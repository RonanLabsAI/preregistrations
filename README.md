# RonanLabs preregistrations

Public record for approved research plans and run outcomes. Stephen approved repository creation on 2026-11-14 (PT).

Each study records its execution state explicitly. An approval reservation or draft is not a frozen executable preregistration. Before new execution, commit the complete frozen protocol and public input identities, and record the exact file SHA-256 and immutable public commit URL in the result package. A later timestamp never retroactively preregisters earlier work.

Every preregistered run outcome is recorded here, including nulls, deviations, interruptions and unrun dispositions. Posts and papers cover meaningful nulls only; the PI decides the tier. See [POLICY.md](POLICY.md).

No confidential material, personal records, credentials or model weights belong here.
